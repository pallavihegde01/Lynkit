# Lynkit – Real-Time Communication Platform

A full-stack real-time communication platform that provides secure user authentication, instant chat messaging, and high-quality video calling. The application integrates Stream APIs for chat and video features while maintaining a smooth user experience with protected routes, onboarding flows, and modern UI components.

---

## Features

- Secure login and signup with JWT authentication
- Protected routes with user onboarding flow
- Real-time chat messaging using Stream Chat API
- High-quality video calling using Stream Video API
- User profile setup with avatar and personal information
- Chat invitation and channel handling
- React Query for state management, caching, and API mutations
- Toast notifications and clean, responsive UI
- Modular and scalable backend structure

---

## Tech Stack
**Frontend:** 
- React.js
- TanStack React Query
- Axios
- Tailwind CSS
- DaisyUI

**Backend & Services:**
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- bcrypt
